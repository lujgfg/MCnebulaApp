## `MCnebulaApp`: A user-friendly shinyapp designed for LC-MS/MS data analysis within the MCnebula workflow.

# **About**

# **Installation**

Please install packages of [MCnebula2 and exMCnebula2](https://mcnebula.org/docs/installation/) first.

``` r

if (!require('remotes')) install.packages('remotes');
remotes::install_github("lujgfg/MCnebulaApp")

```

# **Start**

``` r
library(MCnebulaApp)
run_MCnebulaApp
```
